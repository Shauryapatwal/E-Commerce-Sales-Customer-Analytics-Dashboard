# E-Commerce Sales & Customer Analytics Dashboard | Microsoft Excel

Built an interactive Excel dashboard analyzing 31K+ e-commerce transactions across sales channels, product categories, customer demographics, order status, and geography. Cleaned and transformed raw data using Excel, developed PivotTables/PivotCharts and interactive slicers, and generated business insights on channel, category, monthly and regional performance.
